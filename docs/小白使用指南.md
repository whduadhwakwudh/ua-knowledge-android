# UA 知识库 APK —— 小白使用指南

> 这份指南是给**完全不懂技术的人**看的。照着做就行，不用理解原理。
> 如果你卡在某一处，把截图发给给你 APK 的人（管理员），他会帮你解决。

---

## 一、安装 APK（2 分钟）

1. 用手机浏览器打开给你 APK 的人发来的 **下载链接**（GitHub Release 页面或直接发的文件）
2. 下载 `UA-debug-*.apk` 这个文件
3. 点开它，手机会提示「**不允许安装来自此来源的应用**」——点「设置」→ 允许「此来源的应用」（或打开「安装未知应用」开关）
4. 返回点「安装」→「完成」
5. 桌面出现一个 **UA** 图标，点开

> 如果手机提示"有风险"或"未知来源"，是正常的——这不是应用商店的应用，自己安装都会这样提示。装完可以用。

## 二、首次打开：连接知识库（1 分钟）

打开 App 后是"尚未连接知识库"的页面，需要两样东西（**找管理员要**）：

- **服务器地址**：例如 `https://kb-api.example.com`（管理员给你一串网址）
- **设备令牌**：一串以 `uak_` 开头的密码（管理员专门给你签发的）

操作：

1. 点「**去连接**」（或「我的」→ 设置 →「知识库连接」）
2. 服务器地址：**复制粘贴**管理员给的网址（不要手打，容易错）
3. 设备令牌：**复制粘贴**管理员给的那串密码
4. 点「**保存**」
5. 回到首页点「**立即同步**」——等进度条走完

完成后就能看到笔记列表了。**以后每天内容有更新，点一次「立即同步」就能拿到最新内容。**

## 三、日常怎么用

### 📖 看笔记
- 首页就是笔记列表，点任意一条进去阅读
- 列表是**随机排序**的（每次打开都不一样，方便回顾）；想换一批点右上「换一批」
- 顶部可以按分类筛选：**全部 / wiki / outputs / raw**（分别是长期知识 / 任务产物 / 原始资料）

### 🔗 笔记里的蓝色链接
- 正文里**蓝色的虚线链接**都可以点：
  - `[[笔记名]]` → 跳转到那篇笔记
  - `S024` 这类编号 → 跳转到对应的原始资料
- 跳过去之后，按**返回键**会回到原来那篇，不会直接退出
- 笔记底部有「**反向链接**」：列出"哪些笔记提到了当前这篇"，点它也能跳

### 🔍 搜索
- 首页顶部搜索框输入关键词，自动全文搜索所有笔记（离线也能搜）

### ⭐ 收藏
- 看笔记时点右上角**星标**收藏；底部「收藏」页查看所有收藏

### 🤖 智能助手（可选功能）
- 底部第 4 个 tab「助手」，像聊天一样提问
- 助手会**优先从知识库里找相关内容回答**，并标注来源（如"来源：wiki/xxx.md"）
- 需要管理员帮你配置 API Key 才能用；没配的话会提示"助手未配置"

### ⬆️ 更新 App
- 「我的」→「关于」→ 发布包 → 下载最新版安装即可（App 内直接升级）

## 四、常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 点同步提示"网络不可达" | 网络问题或服务器没开。**已下载的内容仍可离线阅读**，网络好了再同步 |
| 提示"认证失败" | 令牌失效了，找管理员重新签发 |
| 提示"数据校验失败" | 一般等一会重试同步即可；还不行就找管理员 |
| 打开是空白/没有内容 | 还没同步成功，先点「立即同步」 |
| 助手提示"未配置" | 管理员没给这个设备配 API Key，问管理员 |
| 别人打开什么也看不到 | 正常——内容需要"服务器地址 + 自己的令牌"，只有管理员签发才能看 |

## 五、给管理员的话（非小白部分）

给小白使用只需两步：

```powershell
# 1. 在部署了同步服务的电脑上，为小白签发设备令牌（只打印一次，记下发给对方）
cd D:\ua-knowledge-sync
npm run token -- create --label "朋友设备名"

# 2. 把「服务器地址 + 刚打印的令牌」发给小白即可
```

- 令牌可随时撤销：`npm run token -- revoke --id <设备ID>`（先 `npm run token -- list` 查 ID）
- ⚠️ 提醒：签发的令牌能浏览**你全部知识库内容**（含 raw 原始资料），只给信任的人

*有问题先试「重启 App + 重新同步」，90% 的问题都这样解决。*
