# 小白自建知识库服务器指南

> 目标：在一台普通电脑上搭一个"自己的知识库服务器"，手机装 App 后随时看**你自己**的 Markdown 笔记。
> 全程照做即可，不需要懂编程。预计 30 分钟。看不懂的术语都给了通俗解释。

---

## 你需要准备

| 东西 | 说明 |
|---|---|
| 一台 **Windows 电脑** | 平时开着的（或笔记本），装服务器用 |
| **Node.js** | 运行服务器的环境（免费），下面教你装 |
| 你的 **Markdown 笔记文件夹** | 就是平时存 `.md` 笔记的文件夹，放服务器上供手机读取 |
| 一台 **Android 手机** | 和电脑连**同一个 WiFi**（最简方案） |

> 原理一句话：电脑上跑一个"文件服务器"，把你笔记文件夹的内容通过 WiFi 提供给手机 App 阅读。手机只读，不改你的笔记。

---

## 第一步：安装 Node.js（10 分钟）

1. 打开 https://nodejs.org/ ，下载 **LTS 版本**（左边那个，Windows Installer `.msi`）
2. 双击安装，一路「下一步」（不用改任何选项）
3. 装完验证：按 `Win + R`，输入 `cmd` 回车，在黑色窗口里输入：
   ```
   node -v
   ```
   显示 `v20.x.x` 之类的版本号 = 成功。

## 第二步：下载服务器程序（5 分钟）

1. 打开 https://github.com/whduadhwakwudh/ua-knowledge-sync
2. 点绿色 **Code** 按钮 → **Download ZIP**
3. 解压到一个固定位置，比如 `C:\ua-knowledge-sync`（路径不要有中文）

## 第三步：配置你的知识库（3 分钟）

1. 在 `C:\ua-knowledge-sync` 文件夹里找到 **`.env.example`** 文件
2. 用记事本打开，**另存为** `.env`（文件名去掉 `.example`，注意前面有个点）
3. 编辑 `.env`，改成你的信息（用记事本，另存时编码选 UTF-8）：
   ```
   UA_VAULT_ROOT=D:\我的笔记            ← 改成你的笔记文件夹的完整路径
   UA_BIND_HOST=0.0.0.0                 ← 保持这个（允许局域网手机访问）
   UA_PORT=8790                         ← 保持这个（端口号）
   ```
   > 你的笔记文件夹里放 `.md` 文件即可；如果分目录（如 `wiki`、`outputs`、`raw`）也会按目录显示。

## 第四步：启动服务器（5 分钟）

1. 在 `C:\ua-knowledge-sync` 文件夹的地址栏输入 `cmd` 回车（打开命令行，且已定位到该文件夹）
2. 依次输入并回车（每行等它跑完）：
   ```
   npm install
   npm run build
   npm start
   ```
3. 看到 `server listening` / 没有报错 = 成功。**这个窗口不要关**，关了服务器就停了

> 验证：手机浏览器打开 `http://电脑IP:8790/v1/health`（电脑IP见第五步）应显示 `{"ok":true}`。

## 第五步：查电脑 IP 并放行防火墙（3 分钟）

1. **查电脑 IP**：命令行输入 `ipconfig`，找「无线局域网适配器」里的 **IPv4 地址**，形如 `192.168.1.50`（记下来）
2. **放行防火墙**（否则手机连不上）：命令行输入下面命令并回车：
   ```
   netsh advfirewall firewall add rule name="UA-Knowledge" dir=in action=allow protocol=TCP localport=8790
   ```
   看到"确定"= 成功。

## 第六步：给手机签发"钥匙"（1 分钟）

服务器命令行（保持 `npm start` 在跑，另开一个 cmd 到同一文件夹）输入：
```
npm run token -- create --label "我的手机"
```
会打印一行 `uak_` 开头的长串——**这就是你手机的钥匙，复制保存好**（只显示这一次）。

## 第七步：手机装 App 并连接（5 分钟）

1. 手机下载安装 APK（https://github.com/whduadhwakwudh/ua-knowledge-android/releases 最新版），允许"安装未知来源"
2. 打开 App → 「去连接」，填写：
   - **服务器地址**：`http://电脑IP:8790`（例如 `http://192.168.1.50:8790`）
   - **设备令牌**：粘贴第六步那串 `uak_` 开头的钥匙
3. 「保存」→ 首页「立即同步」→ 等进度条走完 → 你的笔记都在手机上了

---

## 日常使用

- **看新笔记**：往笔记文件夹里加/改 `.md` 文件 → 手机点「立即同步」即可（服务器在跑就行）
- **电脑重启后**：重新到 `C:\ua-knowledge-sync` 打开 cmd 跑 `npm start`（进阶：可以设开机自启，见文末）
- **手机不在家**：局域网方案只能在家用；想随时都能连，看下面的「远程同步」

## 远程同步：随时随地都能看（不需要在家）

"局域网方案"只有在家（同一个 WiFi）能用。想出门在外也能同步，**推荐 Tailscale**——电脑和手机各装一个应用、登录同一个账号，就相当于给两台设备拉了一条加密的"虚拟网线"，任何网络都能互通。免费、不需要域名、不需要公网 IP。

### 方式一：Tailscale（推荐，5 分钟）

1. **电脑**：打开 https://tailscale.com/download ，下载安装 Windows 版，注册并登录账号（免费）
2. **手机**：应用商店搜 **Tailscale** 安装，**登录同一个账号**
3. 电脑上打开 Tailscale 界面，记下你电脑的 **Tailscale IP**（形如 `100.101.102.103`）
4. 确认电脑上的服务器还在跑（`npm start` 的窗口开着；或已设置开机自启）
5. 手机 App 里把「服务器地址」改成：
   ```
   http://100.101.102.103:8790
   ```
   （替换成你自己的 Tailscale IP）
6. 保存 → 立即同步 → 之后**任何网络**（4G/5G/别人家 WiFi）都能同步了

> 原理一句话：Tailscale 让"电脑和手机"永远像连着同一根网线，不管实际在哪个网络。

### 方式二：cloudflared 隧道（固定的 https 公网地址，需要域名）

如果你想要一个固定的 `https://你的域名` 地址（更接近"正规服务器"的样子）：

1. 注册 Cloudflare 账号（免费），买一个域名（约 ¥30/年）
2. 电脑安装 cloudflared，建一条隧道指向 `http://localhost:8790`
3. 在 Cloudflare 控制台把 `kb.你的域名` 解析到这条隧道
4. 手机服务器地址填 `https://kb.你的域名`（https，任何网络可连）

> 这是进阶操作，卡住可以让懂网络的朋友帮忙；项目文档 `docs/operations.md` 有完整的运维说明。

### 方式三：云服务器（VPS，最稳但花钱）

把服务器装到云上（如 RackNerd / 阿里云轻量服务器），服务常开、永不关机。适合把知识库当"重要基础设施"时再上。

## 常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 手机提示"无法连接" | ① 电脑服务器窗口还开着吗？② 防火墙放行了吗？③ 地址里的 IP 对不对？ |
| 手机和电脑同一个 WiFi 但连不上 | 有些路由器开"AP 隔离"，到路由器设置里关掉 |
| 提示"认证失败" | 钥匙（令牌）填错或已撤销，重新签发 |
| 提示"数据校验失败" | 等一会重新同步，或检查 `.md` 文件编码（用 UTF-8） |
| 助手提示"未配置" | 可选功能：在 `.env` 里填 `UA_LLM_API_KEY=sk-你的DeepSeekKey` 后重启服务器 |

## 进阶（可选，等基础用顺了再看）

- **开机自动启动服务器**：参考项目里 `docs/operations.md` 的"自启"部分（计划任务）
- **随时随地能连（不只在家）**：需要内网穿透（cloudflared 隧道）或一台云服务器（VPS）——这两项需要一点技术功底，建议让懂的人帮忙，或等基础方案稳定后再学
- **多个设备**：每个设备都执行一次第六步，签发各自的钥匙；不用的钥匙可撤销

---

*照做顺序：装 Node → 下载解压 → 改 .env → npm install/build/start → 放行防火墙 → 签发钥匙 → 手机连接。卡住就回来看"常见问题"。*
